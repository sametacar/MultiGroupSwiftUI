
# Weather Widget Uygulaması
OpenWeather Api kullanılarak yapılmış bir IOS Hava Durumu Widget ve Live Activity uygulaması. SwiftUI, WidgetKit ve ActivityKit ile geliştirilmiştir.

### Özellikler
- Sadece İstanbul şehrinin hava durumunu gösterir.
- 3 Farklı Widget Boyutu kullanıldı: Küçük, orta, büyük.
- 5 dakikada bir otomatik günceller hava durumunu.
- App Groups yapısı ile uygulama ve widget veri paylaşımı yapar.

### Teknolojiler
- SwiftUi
- WidgetKit
- AppIntents
- App Groups
